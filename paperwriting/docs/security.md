# 数据与安全边界

## 默认不携带什么

发行目录没有真实 `.env`、API 密钥、论文、PDF、模板、SQLite 数据库、图检查点、备份、历史会话、向量权重或私人评测语料。测试用的短文本是合成夹具，不会进入工作台默认数据。

## 使用过程中会产生什么

- `data/` 保存正文、文献、上传文件、版本和模型输入输出/检查点，可能包含敏感研究内容。
- `.cache/` 保存可选向量模型权重。
- 数据备份 ZIP 包含私人内容，不应随源码上传。
- 使用云端生成模型时，相关论文/材料文本会发送给配置的供应商；本地向量编码不发送文献给远程 embedding API。

`.gitignore` 已排除上述运行目录、配置文件和常见研究文档格式，但不要使用强制添加绕过规则。忽略规则也不能移除已经存在于 Git 历史里的秘密。

## 运行范围

程序只监听 `127.0.0.1`，面向本机单人使用；没有账户登录、租户隔离、完整公网防护或部署配置。不要仅通过端口转发、隧道或改监听地址把它开放出去。

现有路径校验、跨站写入检查、审批与章节边界测试是局部保护，不是完整安全审计。提示注入仍可能污染授权章节的语义，引用编号合法也不能保证引用支持结论。

只上传你信任且可以处理的文件。作者必须核查数字、引用、结论、翻译和最终导出的版式。

## 日志与追踪

LangGraph 执行显式关闭 LangSmith 追踪。模型密钥不通过状态 API 返回。任务输入、候选、审阅意见和回执仍会在本地持久化，不是无痕模式。

提交 issue 时只提供脱敏的错误信息、环境和合成复现数据，不要附 `.env`、完整数据库、未发表论文或带 Authorization 的请求记录。
